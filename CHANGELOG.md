# Changelog

## 1.0.0

### Added

- Sync the desktop app with a server, with an offline copy of its data
- Link several servers and accounts, each with its own copy, and switch between them
- Add other Termix servers as remote sites with an API key and see their hosts and health
- Open sessions on remote site hosts, connecting through the remote server
- Client type and device id in the sync handshake, and documented sync endpoints
